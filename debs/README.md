# debs/

Сюда кладутся файлы `.deb`. Имя файла — любое, но лучше держать вид
`package_версия_архитектура.deb` (Sileo/Zebra показывают метаданные из самого
пакета, а не из имени файла).

Важно: в одном репозитории могут лежать **оба** варианта сборки одного твика:

| Архитектура      | Джейлбрейк                                | Куда ставится      |
|------------------|-------------------------------------------|--------------------|
| `iphoneos-arm`   | rootful (palera1n rootful, checkra1n…)    | `/`                |
| `iphoneos-arm64` | rootless (palera1n rootless, Dopamine…)   | `/var/jb`          |

Sileo/Zebra сами отфильтруют несовместимые и покажут только подходящие.

Скачать первую партию файлов: `powershell -ExecutionPolicy Bypass -File repo-tools\download-debs.ps1`
