# SETUP — пошагово: от репозитория до рабочего арсенала

Устройство: iPhone 7+ (A10), iOS 15.8.7, джейлбрейк (rootless или rootful).
Источник: `https://resolveq-q.github.io/repo/`

---

## Этап 0. Проверить, что у тебя вообще за джейлбрейк

Открой **Sileo → вкладка «Пакеты» → найди любой установленный твик**. Если пакеты
называются `..._iphoneos-arm64` — у тебя **rootless** (файлы в `/var/jb`),
если `..._iphoneos-arm` — **rootful** (файлы в `/`).

Точная проверка (понадобится терминал, этап 2): `dpkg --print-architecture`.

Почему это важно: rootless-пакет не встанет на rootful и наоборот, а путь к
конфигам у них разный (`/var/jb/var/mobile/Library/Preferences/...` против
`/var/mobile/Library/Preferences/...`).

## Этап 1. Установить базу из Sileo

1. Sileo → вкладка **Источники** → твой репозиторий → потянуть вниз (обновить).
2. Установить по одному:
   - **NewTerm 3** — терминал (без него дальше никак);
   - **Choicy** — отключение твиков для отдельных приложений;
   - **AltList** — зависимость Choicy (подтянется сам).
3. После установки — respring.

**Что происходит под капотом:** `.deb` — это `ar`-архив из трёх частей:
`debian-binary`, `control.tar.*` (метаданные) и `data.tar.*` (сами файлы).
`dpkg` распаковывает `data.tar` в префикс (`/var/jb` для rootless), регистрирует
пакет в `/var/jb/var/lib/dpkg/status` и запускает postinst-скрипт.
Sileo не даст поставить пакет, пока не разрешены его зависимости — поэтому все
зависимости лежат в одном репозитории с пакетами.

## Этап 2. Первый запуск терминала и понимание окружения

Открой **NewTerm 3**. Проверь:

```sh
whoami                          # root или mobile
dpkg --print-architecture       # iphoneos-arm64 = rootless, iphoneos-arm = rootful
echo $PATH                      # должен содержать /var/jb/usr/bin (rootless)
uname -a
```

**Как работает:** NewTerm — обычное приложение, но запускает шелл не из песочницы,
а из бутстрапа джейлбрейка. Всё, что ты ставишь через apt, кладётся в
`/var/jb/usr/bin` (rootless) или `/usr/bin` (rootful). Пользователь `mobile` —
это твои права без root; `root` получается через `sudo` или запуском от админа.

Если `apt-get`/`dpkg` не найдены — бутстрап битый, дальше нет смысла идти.

## Этап 3. Аудит телефона (ничего не меняет)

```sh
curl -fsSL https://resolveq-q.github.io/repo/tools/tune.sh -o /tmp/tune.sh
sh /tmp/tune.sh
```

Скрипт печатает 8 блоков и **только чистит кеш apt** — ничего не удаляет:

1. версия iOS, архитектура, ядро, префикс;
2. место на диске;
3. аккумулятор: `CycleCount`, `DesignCapacity`, `AppleRawMaxCapacity`, температура;
4. топ-12 процессов по CPU — это ответ на «кто ест батарею»;
5. сколько dylib-твиков внедрено и сколько весит каждый (по размеру видно тяжеляк);
6. все репозитории и их количество;
7. `apt-get clean`;
8. чеклист настроек iOS — вот он реально экономит батарею.

Сохранить отчёт, чтобы показать: `sh /tmp/tune.sh > /tmp/tune-report.txt`.

**Как читать:** если аккумулятор < 80% — оптимизация бессмысленна, нужна замена.
Если твиков 40+ — режь. Если в топе CPU постоянно `SpringBoard`/`backboardd`
с 20%+ в простое — виноват какой-то твик.

## Этап 4. Установка CLI-арсенала

```sh
curl -fsSL https://resolveq-q.github.io/repo/tools/gettools.sh -o /tmp/gettools.sh
sh /tmp/gettools.sh
```

Что делает скрипт по шагам:

1. `apt-get update` — обновляет списки пакетов (ошибки отдельных репозиториев
   печатает, но работу не прекращает);
2. идёт по списку: `netcat`, `socat`, `nmap`, `tcpdump`, `ngrep`, `whois`,
   `dnsutils`, `iproute2`, `procps`, `htop`, `curl`, `wget`, `git`, `jq`,
   `openssl`, `gnupg`, `rsync`, `unzip`, `file`, `less`, `nano`, `vim`, `tmux`,
   `lsof`, `python3`, `python3-pip`, `perl`, `exiftool`, `openssh`;
3. для каждого: сначала `apt-cache show` — есть ли пакет в твоих источниках,
   потом `apt-get install -y --no-install-recommends`, лог в `/tmp/gt_<пакет>.log`;
4. печатает таблицу «что теперь доступно» через `command -v` (то есть реально
   исполняемый файл, а не «вроде установилось»).

Обозначения: **OK** — поставилось, **SKIP** — нет в источниках (не ошибка),
**FAIL** — есть в источниках, но установка не прошла (смотри лог).

### Флаг `--osint` (Python-инструменты)

```sh
sh /tmp/gettools.sh --osint
```

Дополнительно делает `pip3 install`: `sherlock-project`, `holehe`, `socialscan`,
`h8mail`, `dnspython`, `shodan`. Часть пакетов на iOS не собирается (нужны
C-расширения) — это нормально, скрипт печатает FAIL и идёт дальше.

**Как работает apt:** скачивает `.deb` из источника → `dpkg -i` → зависимость,
которой нет, ставится рекурсивно. Поэтому **SKIP по одному пакету часто означает,
что в твоих источниках нет вообще ни одной утилиты** — источник бутстрапа сдох
(так умер `apt.procursus.com`). Тогда этап 5.

## Этап 5. Если SKIP много — iSH из App Store

1. App Store → **iSH** (бесплатно).
2. В iSH (это Alpine Linux в песочнице приложения):

```sh
apk update
apk add python3 py3-pip nmap nmap-scripts whois bind-tools socat netcat-openbsd \
        git curl jq exiftool sqlmap nmap-scripts
pip install sherlock-project holehe socialscan h8mail
```

**Как работает:** iSH исполняет x86-код через эмуляцию внутри iOS-приложения —
поэтому пакеты берутся из Alpine-репозитория (`apk`), а не из apt, и root не нужен.
Внутри iSH своя файловая система (не твоя iOS), свои пути (`/root`, `/home`).

**Ограничения, которые нельзя обойти:**
- нет raw-сокетов → `nmap` работает только `-sT` (connect-скан), `-sS` и `-O` нет;
- нет `tcpdump` по системному интерфейсу;
- x86-эмуляция → медленно и греет телефон.

## Этап 6. Как этим пользоваться (только свои сети!)

**Своя сеть и устройства:**
```sh
ifconfig en0 | grep 'inet '          # мой IP и подсеть
nmap -sn 192.168.1.0/24              # кто в сети (ping-скан)
nmap -sT -F 192.168.1.1              # быстрый TCP-скан своего роутера
nmap -sT -sV -p 1-1024 192.168.1.10  # версии сервисов на своём устройстве
```

**Свой трафик:**
```sh
tcpdump -i en0 -n -c 30              # 30 пакетов в консоль
tcpdump -i en0 -n -w /tmp/cap.pcap   # в файл, потом открыть в Wireshark на ПК
```

**Домены, DNS, сертификаты (OSINT):**
```sh
dig +short A example.com
dig +short TXT example.com
whois example.com | head -30
curl -sI https://example.com | head -15
curl -s "https://crt.sh/?q=%25.example.com&output=json" | jq -r '.[].name_value' | sort -u
```

**Метаданные файлов (самое результативное в OSINT):**
```sh
exiftool IMG_0001.JPG
exiftool -a -G1 -s file.pdf | head -40
file *, sha256sum *
strings suspicious.bin | head -50
```

**Никнеймы и e-mail (нужен python3/pip или iSH):**
```sh
sherlock username            # аккаунты по нику на 400+ сайтах
holehe mail@example.com      # где зарегистрирован e-mail
socialscan user@mail.com
```

**SSH на компьютер — правильный способ делать тяжёлое:**
```sh
ssh user@192.168.1.5
# дальше весь nmap/sqlmap/перебор — уже на ПК, телефон только как терминал
```

## Этап 7. Оптимизация под «долго и быстро»

1. Аккумулятор → Состояние аккумулятора: < 80% → замена.
2. Меньше твиков: цель 10–15. Choicy → отключить инъекцию для игр/тяжёлых приложений.
3. Настройки iOS: обновление контента, автообновление ПО, аналитика, службы
   геолокации, «Привет, Siri», значки уведомлений, почта «Вручную».
4. Универсальный доступ → **Уменьшение прозрачности ВКЛ**, **Уменьшение движения ВКЛ**.
5. Speedster → сегмент **2**.
6. Меньше репозиториев в Sileo — каждый тормозит `apt update`.
7. Никаких «ускорителей памяти» и «чистильщиков» — это хуки-паразиты.
8. Под нагрузкой снять чехол, не заряжать, держать 20–80%.

## Шпаргалка «почему не качается»

| Симптом | Причина | Что делать |
|---|---|---|
| `522` / пустые репозитории | фильтрация трафика до чужого источника | пользоваться своим репозиторием на github.io |
| `SKIP` на все утилиты | источник бутстрапа мёртв (`apt.procursus.com` не существует) | iSH (этап 5) или просить зеркало |
| `dpkg: dependency problems` | не хватает зависимости не из твоего источника | ставить из одного источника, обновить списки |
| `Permission denied` при `tcpdump` | нужен root | `sudo tcpdump ...` или запуск от root |
| `pip: command not found` | нет `python3-pip` | `apt install python3-pip` или iSH |
| SpringBoard в safe mode | твик несовместим | выключить последний установленный, `ldrestart` |
